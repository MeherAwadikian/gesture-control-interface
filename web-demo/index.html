Gesture-Controlled Computer Interface

A local Python desktop app that turns webcam hand gestures into real mouse, click, drag, scroll, and system-volume control.

This page is a landmark-detection demo only. The hand tracking below runs for real, live, in your browser (MediaPipe Hands WASM build + your webcam via getUserMedia — nothing is sent to a server). It draws landmarks exactly like the real app does. It does not move your mouse, click anything, scroll, or change your volume — browsers are deliberately sandboxed from controlling the OS cursor or system audio for security reasons, and Cloudflare Pages/Workers have no webcam or OS access at all. The full mouse/click/drag/scroll/volume control app is a local Python program — see install instructions below.

Install & run the real app locally

git clone https://github.com/MeherAwadikian/gesture-control-interface.git
cd gesture-control-interface
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py

Press g to toggle gesture control on/off, q to exit safely (releases any held mouse button and closes the webcam).

Architecture notes

Debounce

A raw per-frame gesture guess is noisy. A StabilityTracker only "confirms" a gesture after it repeats for N consecutive frames (~0.2-0.4s), and flags the single frame it newly became confirmed — so discrete actions (like a volume step) fire once per gesture, not once per frame.

Smoothing

An exponential moving average smooths the mapped cursor position across frames before it's sent to the OS, cutting landmark jitter.

Click vs. drag

Mouse-down fires on pinch-start, mouse-up on release — exactly how a real mouse button distinguishes a click from a drag, by hold duration and movement, with no separate "fire a click" special case needed.

Real system volume

Uses pycaw (Windows Core Audio Endpoint Volume API) for direct volume control, with an honest fallback to simulated media keys if pycaw/COM isn't available — the app reports which backend is actually active rather than claiming real control it doesn't have.
